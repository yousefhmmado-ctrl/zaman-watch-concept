# ZAMAN · زمان

Concept website for a watch brand, presented as a design exercise. Arabic, right-to-left.

- `website/`: home page (watch slider with live hands) and the all-watches page (animated multi-angle viewer)
- `brand/`: design tokens, logo, and the watch renderer (`watch.js`)
- `brand/watches/`: photoreal Blender renders (watch body plus separate hand layers so the hands move live)

Concept brand, for presentation only.
